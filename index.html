FEATURES

Small shell. Real Unix concepts.

N-Shell focuses on the low-level mechanisms behind command execution in a Unix environment.

01

Process execution

External programs are executed using fork(), execvp(), and waitpid().

02

Pipelines

Commands communicate through Unix pipes using pipe() and dup2().

ls | grep ".c"
03

I/O Redirection

Redirect standard input and output using Unix file descriptors.

<   >   >>
04

Signal handling

Handles SIGINT so Ctrl+C terminates the running command without terminating N-Shell.

05

Built-in commands

Includes commands that execute directly inside the parent shell process.

cd    exit
06

Low-level programming

Built around Linux/POSIX system calls, processes, file descriptors, signals, and inter-process communication.

PROJECT

Learning Linux from the inside.

I built N-Shell to demonstrate my understanding of low-level C programming and the operating system concepts behind Unix shells.

The project works directly with processes, file descriptors, signals, pipes, and Linux/POSIX system calls rather than hiding them behind higher-level abstractions.

  • System calls
