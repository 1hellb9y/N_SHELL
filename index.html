A minimal Unix shell built from scratch.

N-Shell is a small Unix shell written in C to explore process management, file descriptors, pipes, redirection, and signal handling.

FEATURES

Small shell. Real Unix concepts.

The project focuses on core operating-system concepts rather than attempting to replace a production shell.

01

Process execution

Executes external programs using fork(), execvp(), and waitpid().

02

Pipelines

Connects commands using pipe() and dup2().

ls | grep ".c"
03

Redirection

Supports standard input, output, and append redirection using Unix file descriptors.

<   >   >>
04

Signal handling

Handles SIGINT so Ctrl+C terminates the running command without terminating N-Shell.

05

Built-ins

Includes shell-specific commands that must execute directly inside the parent process.

cd    exit
06

Error handling

Handles failures from system calls including fork(), open(), dup2(), and execvp().

PROJECT SCOPE

Intentionally minimal.

N-Shell is an educational systems-programming project focused on understanding how Unix shells interact with processes and file descriptors.

Not currently supported
  • Job control
  • Shell scripting
  • Wildcard expansion
  • Environment variable expansion
  • Complex quote parsing
